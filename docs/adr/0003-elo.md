# ADR 0003: Pairwise Elo for hotness votes

- Status: Accepted for MVP
- Date: 2026-11-01

## Context

Voters can more easily choose between two portraits than assign an absolute 1–10 score. The ranking is explicitly subjective.

## Decision

Use pairwise Elo with initial rating 1500 and K=24 for the first community ranking. Select nearby ratings for most duels and reserve some random pairings for exploration. Keep lookalike similarity separate from hotness ranking. Record each duel and vote as an immutable event; apply rating changes in one database transaction and make each duel vote idempotent.

## Consequences

Elo produces a relative ordering from observed choices, not an objective attractiveness score. The initial public version is a single community ranking; per-user rankings can be added later without mixing personal preferences into the community score. Add abuse controls before opening voting broadly.
